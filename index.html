Paris Metro Network Analysis

  • 376 stations in the graph
  • 933 connections between them
  • 1.42s runtime, accepted by the UVA Online Judge (Problem 11710)
Problem
Compute the minimum spanning tree over the transfer hubs of the Paris Metro network.
Built
An adjacency-list graph in Java. Transfer hubs are detected by clustering walking edges with a custom linked-list Union-Find ADT using union-by-size, then Kruskal's algorithm with a priority queue computes the minimum spanning tree over hub-to-hub segments.
